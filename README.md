🌍 MakeTrip – Travel & Tourism Website

MakeTrip is a travel and tourism website designed to showcase beautiful destinations, explore travel packages, and help users plan their journeys through a simple and attractive interface.

The website features a beautiful travel-themed homepage, booking section, travel packages, best places, contact form, and footer.

✨ Website Features

🏠 1. Home

- Attractive navigation bar.
- Website logo/name: MakeTrip.
- Navigation links: Home, Book, Packages, Best Places, Contact.
- Beautiful mountain and lake background image.
- Hero heading: "Amazing Travel Destinations – Make Your Holidays Special".
- Explore button.

🧳 2. Book Your Place

A dedicated booking section with:

- Travel destination input.
- Number of members.
- Arrival date selection.
- Journey end date selection.
- Submit button.
- Attractive booking layout with a travel image.

🏖️ 3. Best Packages

- Travel package cards.
- Beautiful destination images.
- Package names and details.
- Tour duration and pricing information.
- Clean card-based layout.

📍 4. Explore Best Places

A collection of beautiful destinations from India and around the world.

Destinations featured:

- Agra, India
- Goa, India
- Jaipur, India
- Paris, France
- Dubai, UAE
- Santorini, Greece
- Varanasi, India
- London, UK
- Rome, Italy

Each destination is displayed with an image and relevant travel information.

📩 5. Contact Us

- Attractive contact section.
- Contact illustration.
- Name input field.
- Email input field.
- Connect button.

🔗 6. Footer

The footer contains:

- About Us
- Tour links
- Travel links
- Address information

🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and page layouts.
- JavaScript – Interactive functionality.
